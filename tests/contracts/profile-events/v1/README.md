# Eventos de Profile que lee risk

Copias de los ejemplos de `SustainabilityCertificateSubmitted` y `CompanyVerificationRequested`, cuyo contrato es de `vankoo-profile-service` (tópico `vankoo.profile.events`). Si Profile los cambia, hay que actualizar estas copias y `sustainability/interfaces/messages.py` o `verification/interfaces/messages.py`.
